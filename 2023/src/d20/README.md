# Day 20: Pulse Propagation

Both parts share a FIFO pulse simulator. Part 1 completes 1,000 button presses; part 2 observes low pulses reaching rx. Independent branches use state-proven cycles and phase alignment, followed by replay to verify pulse ordering. Coupled networks use whole-network state repetition. Each press must finish processing its pulses. Whole-network search and phase combinations can be costly on large networks.
